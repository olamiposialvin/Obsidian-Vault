1. Define the CPU.
	The CPU, often named the 'brain' of the computer processes data, follows given instructions, coordinates the other components, and controls how data is moved.
2. State the functions of the ALU and the Control Unit.
	The Arithmetic and Logic Unit (ALU) processes calculations, logical operations, and logical comparisons.
	The Control Unit gets instructions from the computer memory, decodes then, sends control signals, and coordinates processing.
3. Explain the functions of the PC, MAR, and MDR.
	The Program Counter (PC) holds the memory address of the next instruction.
	The Memory Address Register (MAR) holds the memory address of the next memory location to access.
	The Memory Data Register (MDR) holds the data or instructions that are moving to or from the memory.
4. What is Von Neumann Architecture
	Von Neumann Architecture is a computer model proposed by John von Neumann in 1945 where data and instructions share the same main memory.
