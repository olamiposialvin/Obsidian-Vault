# Linear and Quadratic Inequalities

## Learning Objectives

1. Define linear and quadratic inequalities and distinguish them from linear and quadratic equations.
2. Identify and correctly use inequality symbols: strict ($<$, $>$) and non-strict/inclusive ($\leq$, $\geq$). 
3. State the fundamental properties of inequalities, specifically the rule of reversing the inequality sign when multiplying or dividing both sides by a negative number.
<br>
4. Solve linear inequalities in one variable algebraically, including those with fractions and brackets.
5. Represent the solution set of a linear inequality on a number line using correct conventions (open circles for strict, closed/solid circles for inclusive inequalities).
6. Solve compound linear inequalities (e.g., $−3 < 2x + 1 \leq 7$) and express the solution in interval notation or set-builder notation.
<br>
7. Solve quadratic inequalities with integral roots by factorizing the expression to find critical values (roots).
8. Use a sign chart or number line to test intervals between critical values and determine the correct solution range (e.g., $a < x < b$ or $x \leq a ∪ x \geq b$).
9. Interpret the solution of a quadratic inequality graphically by analyzing where the parabola $ax^2 + bx + c$ lies above or below the x-axis.
<br>
10. Graph linear inequalities in two variables on the Cartesian plane, correctly using dashed lines (for $<$, $>$) and solid lines (for $\leq$, $\geq$).
11. Determine the feasible (unwanted vs. required) region for a system of simultaneous linear inequalities by testing a point (e.g., the origin $(0,0)$).
12. Apply graphical inequalities to solve basic linear programming problems (e.g., finding maximum or minimum values of an objective function within a feasible region).
<br>
13. Translate real-world word problems (e.g., budget constraints, capacity limits, age restrictions) into mathematical inequality statements.
14. Evaluate the validity of a proposed solution to an inequality word problem by checking it against the practical constraints of the scenario (e.g., ensuring a variable representing "number of people" is a positive integer).
15. Diagnose and correct common algebraic errors in inequality solutions, such as failing to reverse the inequality sign when dividing by a negative or incorrectly identifying the "between" vs. "outside" regions for quadratic inequalities.

## Definitions

An inequality is a comparison between two expressions in magnitude such that one term is either **greater** or **less** than the other.

Inequalities generally use the following signs:
1. $<$ (less than), e.g. $5 < 8$
2. $>$ (greater than), e.g. $11 > 3$
3. $\leq$ (less than *or equal to*), e.g. $12 \leq 8 + 4$
4. $\geq$ (greater than *or equal to*), e.g $15 \geq 10 + 5$

For example: $4 < 7$ compares $4$ and $7$ in magnitude and says that $4$ is **less than** $7$.

A linear inequality is a type of inequality in which both sides are linear expressions. i.e., a linear inequality involves each side being in the form $ax + b$, where $a$ and $b$ are constants.

A linear inequality is structured as $ax + b < cx + d$. Either $a$ or $c$ can be equal to $0$ but not both. The same applies with other inequality signs.

For example: $4x + 5 \geq 7x$ compares $4x + 5$ and $7x$ in magnitude and says $4x + 5$ is **greater than *or equal to*** $7x$.

A quadratic inequality is also a type of inequality in which at least one side is a quadratic expression. i.e., a quadratic inequality involves at least one side being in the form $ax^2 + bx + c$, where $a$, $b$, and $c$ are constants and $a$ is not equal to $0$.

A quadratic inequality is structured as $ax^2 + bx + c > dx^2 + ex + f$. Either $a$ or $d$ can be equal to $0$ but not both. The same applies with other inequality signs.

For example: $\frac{2}{3} x^2 - 5 > 17x + 4$  compares $\frac{2}{3} x^2 - 5$ and $17x + 4$ in magnitude and says $\frac{2}{3} x^2 - 5$ is **greater than** $17x + 4$.

## Fundamental Properties of Inequalities

When handling inequalities, one must consider the following properties of inequalities.

### Transitive

When two inequalities are linked, e.g. $a < b < c$ or $a < b$ and $b < c$, then the middle expression may be skipped, e.g. $a < c$. 

Therefore, if $a < b < c$, or $a < b$ and $b < c$ then $a < c$. The same applies with other inequality signs.

### Symmetric

An inequality's expression can be swapped on either side, and upon swapping, the direction of the inequality would be flipped **($<$ to $>$, $\leq$ to $\geq$, and vice versa)**.

If $a < b$, then $b > a$. The same applies with other inequality signs.

### Addition and Subtraction

Adding or subtracting both sides of an inequality by the same amount does not affect the direction of the inequality, e.g. If $3 < 5$, then $3 + 4 < 5 + 4$ ($7 < 9$)

If $a < b$, then $a + c < b + c$. The same applies with other inequality signs, and with subtraction.

### Multiplication and Division

#### Positive

Multiplying or dividing both sides of an inequality by the same **positive** number does not affect the direction of the inequality, e.g. If $17 > 8$, then $17 \times 11 > 8 \times 11$ ($187 > 88$)

If $a < b$, then $a \times c < b \times c$ for all $c > 0$. The same applies with other inequality signs, and with division.

#### Negative

Multiplying or dividing both sides of an inequality by the same **negative** number flips the direction of the inequality ($<$ to $>$, $\leq$ to $\geq$, and vice versa), e.g. If $180 < 490$, then $180 \div -10 > 490 \div -10$ ($-18 > -49$)

If $a > b$, then $a \times c < b \times c$ for all $c < 0$. The same applies with other inequality signs, and division.

## Inequalities on a Number Line

Placing inequalities on a number line allows you to visualize the values in an inequality. To show the inequalities on a number line, a straight line and at least one circle are drawn to indicate the range of the inequality.

There are two forms of the circle, **open** (the inequality excludes that value, equivalent to $<$ or $>$), and **closed** (the inequality includes that value, equivalent to $\leq$ or $\geq$).

For example, the inequality $7 < x \leq 10$ on the number line is shown as:

## Compound Linear Inequalities

A compound linear inequality is the combination of two linear inequalities. For example: given the two linear inequalities $5 < x$ and $x < 10$ that are connected by $\text{AND}$, they can be combined into the compound linear inequality $5 < x < 10$. However, given two linear inequalities $x < 4$ and $x > 9$ that are connected by $\text{OR}$, they **cannot** be combined into a compound inequality.

	\\ \text{	Reverse $d > 18$ to $18 < d$ to create the compound inequality}

	$$

## Interval Notation

An interval is the set of all real numbers lying between two fixed lower or upper bounds.

Interval notation is a way to describe intervals. Intervals, when written, look similar to the coordinates to a point $(x, y)$. However, they are **not** meant to denote a specific point. Rather, they are meant to be a shorthand way to write an inequality or system of inequalities.

Inequalities or intervals in interval notation are written using rectangular brackets $\left[ \ \right]$ and/or parentheses $\left( \ \right)$ and 2 numbers in-between delimited with a comma. The two numbers are known as the **endpoints** or **boundaries** of the inequality. The left number and bracket/parenthesis represent the lower boundary, while the right number and bracket/parentheses represent the upper boundary.

A rectangular bracket represents **less/greater than or equal to** in the interval. For example: $4 \leq x \leq 9$ would be represented as $\left[4, 9 \right]$. An interval that only uses rectangular brackets are called **closed intervals**.

A parenthesis represents **less/greater than** in the interval. For example: $2 < x < 16$ would be represented as $\left(2, 16 \right)$. An interval that only uses parentheses are called **open intervals**.

Both rectangular brackets and parentheses can be used for a single interval. For example: $17 \leq x < 23$ would be represented as $\left[ 17, 23\right)$. An interval using both rectangular brackets and parentheses is called a **half-open interval**.

When an interval does not have a lower or upper bound, i.e. it extends infinitely in that direction, the infinity symbol ($\infty$) is used in its place. Note that only parentheses can be used with infinity because infinity is **not a number** that is able to be reached or included. For example: $55 \leq x$ would be represented as $\left[55, \infty \right)$, and $x < 21$ would be represented as $\left(- \infty, 21 \right)$

## Set-builder Notation

Set-builder notation is a notation for specifying a set or inequality by a property or condition that characterizes its members. It is written as $\{ \text{variable} \ \mid \ \text{condition} \}$. The variable is usually written as part of the real numbers ($x \in \mathbb{R}$), and the condition is usually the inequality itself. For example: $x > 4$ would be represented as $\{ x \in \mathbb{R} \mid x > 4 \}$.
